## 安装与运行

- 使用官方插件管理器和应用附带的 pnpm 完成安装；已登记为 profile bundle。最终安装文件与本仓库构建内容一致。

- 验收前备份 profile 配置。最终保留正式插件与可信仓库配置；临时探针、临时模块刷新工具、临时仓库根目录均已从 profile 移除。
- Git 使用宿主 PATH；本机没有全局 Hg，已配置仓库内隔离的 Mercurial 7.2.4 可执行文件 `.local/mercurial/hg.exe`。其 Python 路径由该目录中的 `python314._pth` 定义，不修改全局环境。
