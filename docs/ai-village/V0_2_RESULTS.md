> 本文保留 0.2 历史证据。当前 0.3.0 的格式、自主行为和复验结论见 [本轮发行](../releases/notebook-village-2026-10-21.md)。

日期：2026-10-21。交付小院 `0.2.0` 与 Git/Hg `0.1.1`，Live2D 沿用 `0.1.0`。

## 行为

- Git 与小院可同时展开，Git 在上，小院在下，间隔 12px，共用一列 364px 的对话留白。关闭任一个后另一个恢复原可用区域。官方右侧栏展开时两者隐藏，收起后恢复。
- 小院与 Live2D 保持互斥；Git 与 Live2D 的既有互斥行为不变。
- “在场伙伴”支持逐个入住/移出、全员入住、仅留当前，至少保留一位，最多七位。单人模式下拉框更换形象，多人模式下拉框选择在场角色，保留每人的独立状态。
- 每位角色分别行走、待机或使用家具。抓起一人时其他人继续活动；按脚下深度绘制与选取；家具独占，脚下位置避免重叠，无法落脚时还原拖动。
- 世界格式升级为 2，actor 保存当前选中角色，companions 保存其他成员。旧格式 1 原样读取并在内存迁移，首次新保存写入格式 2；保留旧不可变快照，不重置进度。旧版 0.1.0 不支持格式 2。
- 继续复用已验收的七套形象和场景动作；130 张共享纹理不随人数增长，移出成员释放其渲染对象。
