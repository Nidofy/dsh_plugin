`validation.json` 保存原始尺寸、透明/不透明/部分透明像素数、边缘非零 alpha 数、原始 alpha 非零边界、定义与实现哈希、每张截图哈希、每个角色每次的屏幕脚点和容器边界。边缘非零像素包含低 alpha 抗锯齿，单独出现不代表裁切缺陷，不将该计数当成美术批准标准。
