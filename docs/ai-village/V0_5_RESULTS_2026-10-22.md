## 数据、迁移与生命周期

世界采用 schema 5、simulationRulesVersion 2、contentRevision 2、sceneVersion 2；相册独立于世界保存。schema 1–3 沿冻结的历史场景迁移，schema 4 使用保留的解码器读取，进行中的茶会、首次手账和风铃继续保留。首次写入新版本前保护旧指针和快照原字节，升级引用不随普通快照轮换清理。未来版本、未知字段、重复事件标识、不合法参与者及无效关系计数均被拒绝。

世界仍使用原有单 owner、Host epoch、租约、修订 CAS 和确认后发布机制。相册写入另有串行在途操作，归属相同 owner；回执丢失时读取权威状态确认，不自动重放上传或删除。卸载等待在途操作，拍照暂停只移除自身暂停原因，不覆盖用户暂停偏好。

相册上限为 20 张、40 MiB，单张 PNG 不超过 4 MiB。Host 校验固定 ID 路径、文件类型与链接、字节数、SHA-256、PNG 块 CRC、解压长度及逐行过滤标记；不会接收任意路径或任意图像格式。上传图片先持久化，索引通过存档事务发布；删除先更新索引，再清理不再受当前和上一索引引用的托管图片。**删除后，上一索引引用的图片可能暂时保留，直到后续索引更新解除引用。** 未知文件不参与清理。

Host 按请求读取并校验固定清单资源，客户端仅准备在场角色，iframe 完成纹理准备后才恢复世界。移除居民时先销毁对应渲染对象，再释放无用纹理和对象 URL；帧更新不反复复制图片字节。

单份 RGBA 按 PNG 尺寸乘四计算，不代表进程内存或显存峰值；未计入重复分配、画布和缓冲区。离线包保留全部 130 张已审核资产，运行时无需加载两张旧整件家具图。

`node scripts/ai-village-v05-performance.mjs`：七人 5.124 秒样本约 21.47 FPS，父页面 RAF 59.01 Hz，平均 JS 绘制提交 1.46 ms，最大 66.10 ms（含初始化）。0.4 相同脚本基线约 22.14 FPS / 1.42 ms，仅作本机短样本参考。关闭后世界精确不变且 iframe 移除；DPR 1/1.25/1.5/2 模拟、紧凑卡片和展开窗口检查通过。

这些数据来自 Chromium headless/SwiftShader；不等于 GPU 完成耗时，不代表物理 Windows 缩放切换、跨设备性能或长时间 GPU 稳定性。
