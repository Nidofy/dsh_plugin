## 仍需现场证据的项目

这些项目不能用浏览器仿真或自动化次数冒充完成，当前状态为未验收：

一小时连续验收按用户要求暂缓；仅在用户重新要求时运行。其余现场项目如下：

1. Windows 实际 100/125/150/200% 系统缩放、多屏移动；已有 DPR 浏览器仿真仅覆盖坐标计算。
2. 真实中文输入法候选窗和宿主审批快捷键的联动；合成 `isComposing` 只是自动化部分。真实 Desktop 已验证未发送草稿、测试文本附件、侧栏恢复和局部 Escape；物理文件选择器与复杂附件预览仍未覆盖。
3. 系统睡眠/唤醒及物理窗口变化后的行为；不会为了测试擅自让用户电脑休眠。
4. 正常前台 Desktop 帧率及真实 Agent 工作并行。隔离后台载体曾出现父页面约 1 Hz 限帧；不据此宣称前台性能达标。测试未发起付费模型任务。
5. 建议的三位未读设计文档的试玩者，以及七人拥挤、接触/遮挡、双语语气的最终人工视觉评审。自动回放不等于独立人类试玩。

可在上述环境逐项记录系统缩放、窗口状态、步骤、观察结果和截图，签署后才能将“全部现场验收”改为完成。当前不能把“0.6 功能已交付”扩写为“所有设备和人工验收已通过”。
