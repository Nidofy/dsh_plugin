## 数据和几何

- world10/content7/rules4/scene3/preferences3/frame7，新增有界 region1。历史9与内容6冻结在 living-state-v9/play-catalog-v6；历史1–9迁移不动角色、路径、时钟、RNG、棋局、回忆或相册。
- 顶层 actor/companions 是当前区域唯一权威。region.active 仅 courtyard/bookhouse，returns 每区 null 或最多7个有 ID、position、safe、facing 的落点；当前区必须 null。书屋时庭院返回点完整覆盖在场居民；庭院时书屋点可为合法子集，以支持庭院入退住。
- 庭院沿用冻结9校验器；书屋角色在独立 bookhouseScene 中严格校验，历史共享字段通过庭院返回点的 idle 投影进入旧校验器，投影不发布、不保存。未知字段/地区、非法路径、重叠/外来返回 ID 均拒绝。保留48KiB世界上限。
- 庭院 scene3 是既有保存兼容契约；书屋独立几何version1、360×480、可走区与三件家具障碍/热点同源。没有把书屋坐标传入 homeScene 来假装兼容。
- 旅行本身不消耗 ticks/RNG、不改 userPaused/选择ID/长期进度。只在候选副本结束普通短社交和自主 intent；进行中的玩家活动拒绝旅行。非活动区域不模拟。
- 全体在场居民一起旅行；庭院移除/替换成员会在保存回调前清理旧书屋返回点，新加入者下次由确定性合法空位补齐。书屋固定家具，禁止入退住/庭院布置/庭院专属剧情。

## 活动和资源

三个动作复用普通寻路、独占席位与 read/work/sit 行为：书柜选书、阅读桌记笔记、窗边坐下。没有另一套奖励或任务历史，普通活动可取消，也可正常转入自主生活。

书屋使用独立代码背景、书柜、桌和窗座分层，原有纸娃娃与动作部件复用；不加载庭院7张环境纹理。七人目标纹理为书屋121/庭院128，实际测量以最终验收为准。一个当前iframe/Pixi Application，离开释放旧区域纹理与URL，不新建永久渲染循环。

## 切换原子性与首帧

原 commitWorld 在准备目标资源后单次CAS，确认前保留旧世界。资源准备失败不写入；未知回执沿原只读对账，不能重放旅行。确认后按区域重建唯一iframe，旧代际消息与cleanup不能修改新frame；输入/模拟等待目标真实首帧回执，保留用户暂停、隐藏等原原因。渲染失败时持久目标区域不暗中回滚，可按目标重试或冷恢复。

界面仍沿四入口组织，书屋明确显示开发样板，保留共享手账与相册；转场显示区域准备并复用既有 canRevealEntrance/finishEntrance 门禁。
