# 入口主题制作与接收

入口是同一个小院 iframe 前的 DOM 2.5D 展示层。不得新增世界、修改游戏相机、绕过首帧回执或存档事务。海洋/都市主题只需按下述契约交付；本轮没有制作这些素材。

- `id` 是最多48字符的小写字母/数字/连字符标识；`revision` 是正整数。资产 `key` 是固定本地 `entrance/[a-z-]+.png`，不能填写 URL。
- `designSize` 不超过4096×4096；`rect` 与 `pivot` 为归一化数值。裁剪图的 pivot 必须相对裁剪矩形，不能使用全画布轴点。
- 必须各有一个 far/frame/left/right，最多8个图层、8个唯一文件；PNG为8位RGBA。压缩总量≤4MiB、解码像素≤8,000,000；不要用增大预算来掩盖素材问题。
- `layers` 顺序就是绘制顺序。背景/道路在后、门扇居中、石框及前景在前。框与门扇 parallax=0；其余0–1.15。视差驱动上限按母版5px随布局缩放。
- `aperture` 为门洞外包矩形；可选 `portalPolygon` 是3–512个凸多边形顶点，归一化到母版。省略则兼容矩形门洞。`safeApertureRect` 必须完全处于门洞内；它决定覆盖视口四角加16px余量的穿门终点。
- 原始绘画、编辑源、来源说明和逐文件 SHA 必须保留。导入器只接收已提交、未被本地修改的 ART_REVIEW 来源；输出透明裁剪版保持源 PNG 字节，不把重采样说成无损原母版。
- 闭门不能仅按非零Alpha包围盒拼接；须通过双色背景安全门洞探针。梦境主题revision2在原PNG不变时把每扇门横向加宽6设计像素，并保持 `(rect.x + rect.width × pivot.x)` 不变。该值是当前素材的校准，不应套用到其他主题。
- `entranceTiming` 与 `doorAngle` 集中维护时间与内开门角度。不要在主题里注入脚本、CSS或自由动画定义。按当前接口替换素材，无需重写状态机。

## 人工签收后

当前候选没有批准。用户明确签收后再由集成者记录批准依据，更新候选状态为 APPROVED，运行生成器、入口安全回归、真实门庭浏览器矩阵、离线包校验。生产选择器继续只接受 APPROVED。

预览选择只存在于实验夹具构建 alias；`pack.mjs` 不包含 experiments/scripts/src。不得把预览模块挂到正式 client 入口或加入环境变量/网址参数开关。改变发布状态不是测试技巧。
