# world13 自由行走数据契约

world12 的完整解码入口保留为 `living-state-v12.ts`，历史 1–12 验证成功后增加 `manualMove: null`，不消费 ticks/RNG，不移动居民，不改首次事实。当前内容仍 content9，bookhouse2、region1、scene3、rules4、preferences3 不变。frame10 加入经严格校验的地面移动/取消输入和只读居民预览标记。

手动订单最多一个，字段固定为 `actorId / target / route / waitTicks / replans / expires`。目标及每个点必须合法，每段必须可达，路线最多9点；订单居民必须在场、walk、无家具intent，第一点必须等于destination。目标等于末点；等待0–29 ticks、重规划0–3次，期限必须在当前 tick 后且至多1800 ticks。拒绝未知键、非有限数字和与活动/故事/短社交冲突的状态。总世界仍不超过48 KiB。

移动通过原 `residentRoute` 搜索，30Hz固定模拟按17逻辑单位/秒推进，并检查整段和24单位居民间距。只暂停订单居民的自主决策，其他居民继续原步进；临时堵路每30 ticks重试，最多三次，失败在安全位置停止。等待、路线和期限持久化，退出重进不会重置重试预算或用瞬移跳过路径。

点击操作生成候选后经原 `commitWorld` 提交；确认前不发表世界，重复点击受到 pending 门保护。未知回执只读核对，不重发请求。地图选择、悬停和预览不写世界。移动订单完成/推进仍属于原运行世界自动保存节奏。到达、取消、旅行、有效拖放及冲突活动会清理相应意图。

用户暂停、隐藏及关闭暂停模拟时间；冷恢复严格校验全部路线。独立试验覆盖 world12 原指针/快照经过42次保存仍原字节保留。旧版无法读world13；回退只能在隔离profile恢复升级前备份，不能对新档更改版本号或直接覆盖。

新茶会场景仅位于 `experiments/community-next` 几何夹具，没有扩展 RegionId、存档或资源白名单，不改变当前迁移契约。未来开放第三地区须另行冻结 region1/world13并设计迁移。
