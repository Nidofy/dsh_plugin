# 社区地图与自由行动：浏览器验收记录

本记录只覆盖隔离鉴权 Host + 本机 Chromium 软件 GPU，未操作日常 DSH_HOME。脚本为 `scripts/ai-village-community-qa.mjs`，不注入世界、不加速 ticks、不代写坐标；用户操作来自真实按钮、checkbox 和按实际 iframe projection 换算的鼠标点击。每轮单独 profile、输出目录与源/bundle 哈希。实际正式包一致性由最终发行记录另行核对。

## 早期运行与修正

- `dpr1-01`：通过地图五节点、未开放阻止、键盘/Escape、聊天草稿、浏览无世界或revision写入、两个区域往返、隐藏暂停、真实绕障碍移动、暂停及冷恢复、保留拖放。之后脚本调用旧“全员入住”按钮超时；现版本已改为逐个入住，该失败属于QA导航假设，原结果保留。
- 首轮截图发现道路 SVG 被通用图标宽高样式压成很小一块。主线程提高道路选择器优先级，后续展开截图已确认路线可见，并补充实际 SVG 宽高断言。
- `dpr1-02`：Playwright `.check()` 要求同步切换checkbox；居民入住需等待CAS，故工具提前认为点击无效果。改用真实click，等待保存与首帧，再断言已选。不是绕过存档确认。
- `dpr1-03`：拖放精确脚点断言在iframe postMessage到达父页之前读取旧世界。随后保存的failure截图/JSON已显示实际目标 `(290,422)`。改为先等目标脚点出现，再等CAS确认并保持同一精确断言。未修改产品来迁就QA。

## 获批地图正式集成验收

用户随后明确批准社区地图候选。此批准仅覆盖地图地形、五个地标及保持原画的缩小版本；书屋场景、角色方向动作、茶会可玩区域等继续独立门禁。

运行 `node scripts/ai-village-community-qa.mjs map-art-dpr1-01 1 --map-art` 与对应 DPR2 命令：[map-art-dpr1-01](browser/map-art-dpr1-01/result.json)、[map-art-dpr2-01](browser/map-art-dpr2-01/result.json) 均 PASS，各9组检查、18张PNG、9次真实旅行。两轮全部 src 哈希与 index/client/frame bundle 哈希相同；page errors=0、外网请求=0。各自 build.json 同时记录获批资源 manifest 和实际 SwiftShader 渲染器。

新增资源验证：

- 未打开地图时没有地图资源请求；首次打开只请求固定六图，实际DOM图像解码完成，data-art=ready，正常文案不再标注导航示意。
- 地形768×576，五地标各256×256；Blob字节总计1,815,775 B，估算RGBA共3,080,192 B，与 manifest 完全相符，低于2 MiB压缩和6 MiB解码预算。
- 关闭后六图DOM移除，每个Blob URL均被撤销且实际fetch不可访问；重新打开得到新URL且六图可解码。每次旅行也释放地图URL。
- 故意只将本地terrain请求返回503，实际进入fallback示意，零图像/零活跃Blob、世界和revision不变，小院错误状态保持空，已开放区域仍可点击前往。取消故障后重开恢复原画。
- 地图不进入runtime.images或传给iframe的resourceKeys；场景纹理保持庭院≤128、书屋≤121。每轮138个本地地图请求包含故意故障；冷恢复后独立计数84个URL创建/84个撤销/0活跃，打开时不超过6个。冷恢复前后是不同页面计数域，不能把后者当整轮累计。
- URL释放验证的是应用引用生命周期，不证明浏览器GC或GPU驱动立即回收所有内存，也不替代长时间内存曲线。

## 最终加载取消修订与终轮身份
