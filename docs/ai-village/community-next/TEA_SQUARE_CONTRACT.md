## 一条可完整完成的玩法：三杯不同的下午

1. 选三位在场居民组成茶桌，不自动替换故事中角色。检查三座位、路线和冲突后由同一世界 CAS 开始。三人按各自真实路线到桌边，未到齐不得跳阶段。
2. 每人带来一条个性提示：蓝鲸喜欢先听大家说完；Claude 想把杯下的小纸条排成一句话；Gemini 喜欢提出两种不同组合。其他角色使用独立短回应，不伪装为模型生成。
3. 玩家将三个图案杯垫「云 / 叶 / 星」放到三个位置。最多三个位置、三个候选索引；错误可以重排，无倒计时和资源扣除。当前正确顺序由故事持久 seed 派生，不能由渲染 RNG 决定。
4. 三人各到桌侧/留言树走完一个收尾片段；明确点“记住这个下午”完成，CAS 同时记录首次参与者、世界日期、重玩次数与纪念物「三叶茶签」。取消不发奖，重玩不替换首次事实。
5. 手账显示这一次真实故事来源；收藏归入邻里相聚，茶签可收起或摆到广场留言树预定挂点。照片拍到真实摆放结果，不另存第二份奖励状态。

普通生活活动为「挑一杯茶并等朋友」：单人先走到茶点柜，再坐到一个空茶桌位，有界停留后离开；和小院普通 eat 区别是选茶与短偶遇台词。没有后台跨区域居民模拟或真实时间惩罚。
