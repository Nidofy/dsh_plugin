## 美术制作与配准

使用内置 image_gen，以获批原图为身份参考生成补绘部件图集。第一次衣身仍包含袖口，会和独立整臂重复，补做无袖衣身/裙摆；基准图直接裁切的呆毛混入白色头饰，因此另行生成干净呆毛。保留制作中间件与提示词，发行资产不引用这些源图集。

部件在肩部、腿根、尾巴连接和头发覆盖处有实际补绘区域。运行资源来自图集的人工测量区域与 alpha 边界裁切：alpha ≥16 仅用于寻找边界，保留 2px 余量，裁切内部的原始 RGBA 不做改写。没有用矩形拼贴或整体立绘摆动代替拆件，也没有声称放大提升原生细节。

各张图集的实际像素不同，注册空间通过渲染尺寸与 offset 统一；清单同时保存源尺寸、裁切矩形、原生部件尺寸和 SHA-256。20 张部件已经实际重建，不把图集里的视觉排版位置当作运行锚点。

首次合成发现尾鳍连接偏移和侧发遮挡手部，已调整尾部枢轴/重叠与侧发长度。尾根、尾鳍共享继承变换，四肢在衣身和裙摆下有覆盖余量。头饰与鲸鱼图案维持原方向，当前没有整角镜像。

当前重建保留了角色身份与主配色，但独立补绘后的脸部、发束和服装轮廓不是原基准逐像素重建。预览并排展示原图，方便评估差异。用户批准的是阶段 1 基准，新的动作资产保持 `approvedForRelease: false`，不自动视为完成动作视觉验收。

## 动作行为

| 动作 | 可见表现 |
| --- | --- |
| idle | 呼吸、头部微动、眨眼、发束/呆毛/鲸尾跟随 |
| walk | 左右腿反相摆动与交替抬脚；双臂、裙摆和头发轻微跟随 |
| pickup | 轻抬并切换惊讶表情，四肢略张开 |
| dragging | 悬空小幅摆动，四肢和发束单独跟随 |
| put_down | 落地与轻微压缩，最后回到稳定姿态 |

walk 在动作室中原地播放，没有伪装成已完成导航。拖动时间轴仅是编辑工具，角色的鼠标拖放事务属于 P3。工作/吃饭/坐姿没有使用站姿旋转冒充，本轮未实现。

动画时间由调用者传入，采样器不读墙钟、DSH 或存档。暂停保持相位；恢复不补算隐藏时间。预览采用前台 30 FPS 上限，显式隐藏和文档隐藏分别参与判断；一次性片段结束后停止绘制，可重播。pagehide 取消 RAF、销毁容器/纹理并释放 Blob URL。

## 验证范围

执行 `node scripts/ai-village-parts.mjs` 和 `node scripts/ai-village-phase2.mjs check`。最近一次实际结果见 [validation.json](../../packages/ai-village/art/QA/phase2/validation.json)。

- 严格 TypeScript、浏览器离线 bundle 和测试 bundle 构建。
- 引用完整性、PNG 原生尺寸/透明通道/哈希、层级无环、有限锚点、关键帧顺序与循环首尾。
- 双腿反相、切换动作变换连续、惊讶表情、放下最终稳定、非法时间拒绝。
- Chromium 软件 WebGL 下 DPR 1/2；不透明 iframe 无法访问父 DOM。
- 显式隐藏后绘制次数和逻辑时间不增长；一次性动作完成后停止。
- 外部网络请求 0、页面异常 0。预览归档包含运行资产与许可证。
- 白/灰/深色及 96/128px 截图；实际录制 idle/walk/pickup/dragging/put_down，而非离线拼帧动画。

该预览归档仍不是可安装插件。没有真实 Desktop、多窗口所有权、家具遮挡、导航、游戏拖放、硬件性能或世界存档验收。阶段 1 存档试验保留，本轮没有把它直接包装为游戏存档服务。
