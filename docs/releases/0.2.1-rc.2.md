## 适配与离线安装

所有包统一声明 `engines.dsh=0.2.1-rc.2`，DSH peer 统一为该版本，Cordis 4.0.5、Schemastery 3.18.5。构建工具来源与官方运行依赖分离，全部测试改用固定官方源码；验证 worker 的嵌入代码同步到新版官方基线。官方 JSONL 入口已改为模块导出，兼容回归使用实际新版入口检验日志可读性。

本次 tgz 内嵌其第三方运行依赖及 Windows x64 原生二进制，包括 Koffi、Sharp 与共享库的完整依赖；每包附带 `OFFLINE-DEPENDENCIES.json` 及原许可证。未安装平台的 optional 包不会进入交付，移除内嵌依赖的构建脚本。sandbox 诊断 helper 改为自包含 .NET，内含运行时与许可证，无需用户另行联网安装 .NET。

DSH 本体和包管理器须预先安装；插件复用宿主的 DSH/Cordis/React，不打入另一份宿主。通过 Plugins 导入本地 tgz；完整笔记先安装 runtime-adapter，再安装 working-notebook。更新全部所需包后完整退出并重启 DSH。不要自动启用清单内所有包：shared 是库，guard 会拒绝进程和文件操作，只用于专门测试。sandbox 仍无可用的隔离执行后端，本次未改变其预览范围。

## 复现与清理

先运行 `node scripts/prepare-runtime.mjs`，随后按根 README 配置工具来源并执行 setup。提供校验通过的 `DSH_SANDBOX_ARCHIVE`，运行 `npm run sandbox:prepare`。客户端源码测试辅助依赖可用 `npm install --prefix .build/live2d-official-deps --legacy-peer-deps --ignore-scripts --save-exact use-sync-external-store@1.6.0 @types/use-sync-external-store@1.5.0` 准备。

执行 `npm run check` 与 `npm run village:check`。`scripts/clean-obsolete-builds.ps1` 默认只列出过期构建；加 `-Apply` 后删除旧打包/解包/安装临时目录及过期 tgz，保留最新发行包、官方源码/依赖、测试载体、profile 与美术源文件。清理遇到 junction 只移除链接，不递归进入目标目录。
