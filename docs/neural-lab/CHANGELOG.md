# Neural Lab 变更记录

## 0.6.0 · 2026-11-06

- 新增六个独立活动，共47项：三输出MLP、可变B/T/head、两层Transformer、8–24步观察、遮罩修复、断梯度修复。多输出MSE按B×O归一，两层由学生模块实际参与前反向。
- 调试台按所选run展示组件关系、真实shape/check/梯度/冻结源码与layer；最早失败和后续症状分别呈现，未采集不补值。揭示步骤/代码提示先记录帮助。
- 导师可定位真实run/component/check，保留当前草稿与历史运行差异；请求模式和实际unknown帮助分开记录，保留两轮来源。
- 实验组使用原SQLite存储，冻结代码/版本/镜像/尝试帮助、有限顺序网格与总预算；取消等待清理，重启中断且不自动续跑。按学习率分别统计均值、样本SD和排除计数。
- 证据分实现、解释、迁移、调试与观察维度；旧版本不算新活动完成。解释保留失败修复提醒；显式复盘仅自述确认失败，不改判定。
- 完整配置进入实验导出/导入及重放核对。环境准备区分Docker不可用、镜像缺失及检查失败，提供对应操作。
- 统一check/check:full门禁、历史升级、空缓存离线安装、官方Web与Electron实际结果见[v060验收](v060/VALIDATION.md)。检查点、GPU、多文件IDE与任意kernel继续暂缓。

## 0.5.1 · 2026-11-06

- 补齐单文件MLP/decoder运行导出、预览和显式复现；兼容0.5.0同协议文件，导入结果仍不可信。
- 历史运行解释保留来源版本与帮助；解释时帮助和尝试另记，避免串独立周期。
- 导师拒绝畸形/空白状态和请求身份覆盖，同步异常归档为failed，取消优先于完成回执。
- 运行比较列出环境/seed/代码/数据/版本变化与Unknown；隔离旧异步导入/核对/下载返回。
- L04/L12增加梯度、validation、三头、因果与数据切分诊断讲义，不增活动或平行学习数据库。
- 新增数值9错解、受控生命周期5项、导师6项、复现/来源2项、UI3项回归；正式CPU/Web/Electron/离线包与升级证据见VALIDATION。

0.5.0及更早历史见DEVELOPMENT_STATUS和VALIDATION保留段落。
