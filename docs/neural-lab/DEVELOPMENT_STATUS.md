# Neural Lab 0.1.3 发行记录 · 2026-11-02

基于 codex/neural-lab-v0.1 的 050388f 完成 1102 四份评审的可靠性迭代。插件和课包版本为 0.1.3，题目检查版本为 3，宿主固定为官方 rc.5。安装包 77777 字节，SHA256 `263eebc654f4baecc3cec8d56e661fd5af736b80370d5916577655618798fbef`。

- workbench、client-api 与工作台组件分别处理草稿确认、修订冲突、导师请求和运行轮询。同一标签页暂存未确认稿，可下载本地副本并合并。活动、页签切换保持原有滚动规则。
- controller、catalog 和课程输入域增加不同形状、类别、头数、逐行平移及排列。独立参考比较保存输入摘要和失败详情。学生后代持有管道时拒绝不完整结果。
- tutor-context、mentor 和 engine 使用当前草稿与上次执行代码的独立摘要、有界同活动对话、请求模式与交付状态。程序判断、阅读、观察和自述解释分别记录。
- store、owner、RecordsTab 保留 SQLite v1 原始记录，新证据可定位具体运行或作答，旧来源标记 legacy。复习按到期/未来分组。独立 owner 数据库的写锁跟随进程生命周期。
- runner 按不可变镜像 ID 创建并按容器 ID 启动、取消和回收，恢复按数据根标签及运行身份限定。高频事件合并写库，归档超过 4096 项时须停用并移走旧运行目录。
- 发行验证与覆盖边界见 [VALIDATION](VALIDATION.md)。下一阶段的训练接口、独立检查和错误解验收见 [NEXT_PHASE](NEXT_PHASE.md)。
