# 鲸屿皮肤

面向官方 DSH 0.2.1-rc.2。安装本地 tgz 并启用插件后，在官方「设置 → 鲸屿皮肤」打开总开关。配色随官方浅色、深色和系统选项变化；支持背景浓度、角色装饰和恢复官方外观。偏好保存在当前客户端本地，停用卸载撤销样式和主题覆盖。

参考 https://github.com/Nidofy/dsh-deep-whale 的深海女仆工坊视觉；使用官方 theme.overrideTokens 和 settings.section，保留原导航、字号及控件行为。背景为本地离线图片，不向远端请求图片。不要同时启用另一套全局皮肤。
