# AI 小院：五位新角色美术资源 v01

制作日期：2026-10-23。基于 `codex/feature-ai-village-entrance` 的 `6a254cd` / `0.9.0-preview.2`，沿用现有七位居民的 Q 版纸娃娃规范。

打开 **preview.html** 可离线切换动作、表情、大小和底色。五位从左到右为 Seedance、GLM、MiniMax、Llama、Mistral。

## 内容

每位 `characters/<id>/` 包含：

- `parts/`：16 张原生透明 PNG，含四表情头部、躯干、左右常规手臂、左右腿脚、两只工作手臂、两只用餐手臂、完整坐姿、后发、尾巴或饰物。
- `character.json`：1024 × 1024 画布、脚底 `[512,952]`、层级、枢轴、层序和禁止整张镜像的设置。
- `animations.json`：idle、walk、pickup、dragging、put_down 五段部件关键帧。
- `activities.json`：工作、吃饭、休息的部件替换、尺寸、落点与场景驱动动作说明。
- `portrait.png`、`portrait-128.png`：透明拼装立绘和缩小预览。
- `manifest.json`：每张部件的原图、原图哈希、裁切矩形、尺寸、字节数、SHA-256 和定义文件哈希。

`sources/` 保存实际采用的原图集和补绘；`prompts/` 保存完整提示词、输入角色说明和生成／弃用记录；`QA/` 保存部件、拼装、表情、动作、透明底及小尺寸检查证据。`SHA256SUMS.json` 覆盖本交付目录除其自身之外的文件。

## 视觉与制作

| 角色 | 保留的视觉特征 |
| --- | --- |
| Seedance | 紫青渐变发、右侧马尾与环形发饰、白紫青服饰、非对称袜靴 |
| GLM | 黑蓝长发、黑狐耳、白蕾丝发箍、黑白裙、白尖狐尾 |
| MiniMax | 橙发侧辫、白粉帽衫、格纹裙、粉色运动鞋与影音挎包 |
| Llama | 奶白卷发、羊驼耳、蓝色无限符号、宽松毛衣、羊驼拖鞋 |
| Mistral | 金橙红渐变发、红金羽毛帽、白红金衣裙、红尖猫尾 |

角色身份依据用户指定的 `Character-reference` 目录。`seedance.jpg` 内部的“豆包娘”文字不作为重命名依据，角色 ID 仍采用用户指定的 `seedance`。小尺寸下简化了文字、刺绣和小配饰；无额外角色或持剑姿态。

图像由内置 **image_gen** 制作。Sharp 只用于矩形裁切、尺寸配准、拼装与检查图输出，保留源图原生 RGBA；没有以代码绘图替代角色。Seedance 躯干重复袖子已重绘；GLM、Mistral 的后发和部分活动部件已单独补绘。两张带黑底光晕的 GLM 持勺试稿被弃用。源图多数主体 alpha 接近 253，检查同时记录完全不透明和 alpha ≥ 240 像素，未强制覆盖生成的透明通道。

## 验证与接入边界

80/80 PNG 解码、源像素一致性、透明外部、主体覆盖、哈希与引用校验通过。已检查四表情、五段基础动作以及工作／吃饭／休息；48 个时间采样 × 五位角色，浏览器错误和外部网络请求均为 0。已输出 96／108／128 像素与白／灰／深底检查图；大于 32 像素的额外孤立碎片为 0。

预览复用生产 `PaperDoll`、`samplePose`，活动手臂尺寸和运动遵循 `scene.ts`，桌面仅是遮挡示意。美术检查状态为 `art-reviewed`；`approvedForRelease=false` 表示尚未进入生产角色目录和发行验证，不代表要求用户逐图审批。
